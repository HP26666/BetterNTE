BetterNTE - 钓鱼不空军指南

恭喜你发现了这个页面。既然你点进来了，说明要么你真的不会用，要么你就是好奇宝宝。 不管哪种，坐好，我要开始讲了。

一、这东西是干嘛的？

BetterNTE 是一个全自动钓鱼辅助工具，专门为某款含有钓鱼玩法的游戏设计。 它能帮你完成从扔钩到收鱼的完整流程，你只需要——看着它钓。

核心流程是这样的：

  1. 按 F 扔钩 — 鱼竿甩出去，开始等
  2. 等蓝圈出现 — 屏幕上冒出一个蓝色圆圈，说明鱼上钩了
  3. 按 F 拉钩 — 及时收竿，别让鱼跑了
  4. A/D 操控绿点 — 这是最核心的部分：画面上方出现一根绿色横条，里面有个小绿点（实际偏黄），你需要用 A 和 D 键把小点控制在横条范围内。小点往左偏就按 D 推回去，往右偏就按 A 推回去
  5. 绿条消失 = 钓到了 — 弹出结果界面，点击屏幕关闭
  6. 自动循环 — 关闭弹窗后自动再次扔钩，永不停歇

二、使用步骤（手把手版）

Step 0: 以管理员身份运行

这一步必须做。BetterNTE 使用 DirectInput 模拟键盘输入，游戏进程通常以较高权限运行， Windows 的 UIPI（用户界面特权隔离）会拦截来自低权限进程的输入。 简单说就是：不开管理员 = 按了也白按。

使用项目里的 run_admin.bat 启动即可。 启动后看右上角的徽章，显示绿色的「管理员」就对了。 红色「非管理员」的话……你猜怎么着？重开。

Step 1: 配置

如果你已经有保存好的配置文件（.json），直接从「配置管理」下拉框选择，点「加载」，跳到 Step 3。

没有的话，点「新建配置」，继续往下看。

Step 2: 截图 + 框选区域

2.1 截图
在游戏画面处于钓鱼相关状态时，点右侧「截图」区域的「截屏」按钮。 点击后会弹出提示，确认后窗口最小化，5 秒后自动截取当前屏幕。 这 5 秒给你时间把游戏画面切到需要的钓鱼状态。也可以提前截好图用「上传」导入。

2.2 框选绿条+黄点区域
点「绿条 + 黄点区域」按钮，在弹出的截图上拖拽画框，把钓鱼时绿条会出现的那一整片区域框进去。 框大一点没关系，但别框到别的绿色东西（比如草地、树）。

2.3 框选蓝圈区域
同上，框选蓝圈可能出现的位置。一般就在屏幕中间偏下的位置，钓鱼按钮附近。

框选完成后可以点「保存」把配置存下来，下次直接加载。

Step 3: 开钓！

  1. 切到游戏窗口（BetterNTE 会捕获你选择的那个显示器画面）
  2. 回到 BetterNTE，点「开始运行」
  3. 切回游戏，站着别动，看它表演

左侧预览区会实时显示画面，上面画了检测标注：蓝色框是 ROI 区域，绿色框是检测到的绿条，橙色圈是黄点位置。

Step 4: 调参

如果 A/D 控制不够好，可以调整「力度」滑块：

  • 力度低（0~30%）：温柔模式，适合绿条移动慢、小幅度纠偏的场景
  • 力度中（40~60%）：均衡模式，默认值，大多数情况够用
  • 力度高（70~100%）：暴力模式，绿条移动特别快的时候用，按键更猛更持久（字面意思）

紧急停止

  • F8 键：全局热键，任何情况下按 F8 立即停止
  • 鼠标角落：把鼠标甩到屏幕四个角之一也会触发停止
  • 停止按钮：GUI 上的红色按钮

三种保险，总有一种适合你。当然，最好的保险是「别在打副本的时候开着这玩意儿」。

三、算法详解（给好奇的技术党）

3.1 视觉检测 — HSV 颜色阈值法

BetterNTE 不用模板匹配，不用深度学习，就是最朴素但最有效的 HSV 颜色空间阈值分割。

为什么用 HSV 而不是 RGB？
因为 HSV 把颜色信息（Hue，色相）和亮度信息（Value）分开了。 游戏里绿条的颜色固定，但不同场景亮度可能不同。HSV 天然对亮度变化更鲁棒。

检测流程：

  1. BGR → HSV 转换：把截图从 BGR 色彩空间转到 HSV
  2. inRange 二值化：用预设的 HSV 上下界生成掩码（mask），范围内的像素变白，范围外的变黑
  3. 形态学滤波：先开运算（MORPH_OPEN，消除噪点）再闭运算（MORPH_CLOSE，填补空洞），用 3×3 的核
  4. 轮廓检测：在处理好的掩码上找连通域
  5. 面积过滤：太小（< min_area）的轮廓直接丢掉

3.2 绿条检测 — 水平投影法

绿条是横向的条状物，如果只取最大轮廓的包围盒，很可能因为绿条边缘不规则而偏差很大。 BetterNTE 用了更精确的水平投影法：

  1. 先对掩码做垂直投影（按行求和），找到绿条所在的行范围（活跃行 = 和值 > 最大行和的 15%）
  2. 在绿条行范围内做水平投影（按列求和）
  3. 找列和 > 最大列和 15% 的列
  4. 在这些列中找最长的连续段（间隔 > 3 像素视为断开），这就是绿条的真实水平范围
  5. 绿条中心 = (左边界 + 右边界) / 2

这样做的好处是：绿条的中心由其真实几何边界决定，不受形状不规则、两端渐变等因素影响。

3.3 状态机 — 钓鱼流程控制

整个钓鱼流程由一个有限状态机驱动，6 个状态：

状态含义转换条件
IDLE闲着用户点开始 → CASTING
CASTING按 F 扔钩按完 F 等 0.5s → WAITING_BITE
WAITING_BITE等鱼上钩检测到蓝圈 → HOOKING；超时 15s → 回 IDLE
HOOKING按 F 拉钩按完 F 等 0.3s → CONTROLLING
CONTROLLINGA/D 控制绿点绿条连续消失 ~10 帧 → FINISHED
FINISHED钓到了/没钓到等 3s 点屏幕关闭弹窗，再等 → CASTING 循环

还有个防空转机制：如果连续 3 轮什么都没检测到（空循环），自动回 IDLE，避免在非钓鱼场景下疯狂按键。

3.4 A/D 控制 — PD 控制器 + 自适应脉冲

这是 BetterNTE 的核心算法，一个简化版的 PD 控制器（比例-微分）：

输入：

  • dot_x：黄点的水平位置（经 EMA 平滑）
  • bar_center：绿条中心位置（经 EMA 平滑）
  • error_ratio = (dot_x - bar_center) / half_width，归一化到 [-1, 1]

方向判定：

  • error > 0（黄点在中心右侧）→ 按 A（向左推）
  • error < 0（黄点在中心左侧）→ 按 D（向右推）
  • 黄点贴近绿条边缘时，方向锁定，防止穿越

死区：
|error| ≤ threshold 时不动。死区大小随力度 slider 变化： 力度 0% 时死区 = threshold，力度 100% 时死区缩小到 threshold × 0.3。 力度越大越激进，死区越小，反应越灵敏。

P 项（比例）：

p_gain = 0.6 + strength × 0.8              # 增益范围: 0.6 ~ 1.4
p_ms   = (22 + |error_ratio| × 78) × p_gain  # 脉冲时长: 22ms ~ 140ms

误差越大，按得越久。力度 slider 放大这个增益。

D 项（微分）：

d_error  = error_ratio - prev_error_ratio   # 误差的变化速度
d_gain   = 1.5 + strength × 3.0            # 增益范围: 1.5 ~ 4.5
d_factor = clamp(1.0 + d_error × d_gain, 0.20, 2.50)
  • d_error > 0（误差在扩大）→ d_factor > 1 → 加大按键时长
  • d_error < 0（误差在缩小）→ d_factor < 1 → 减小按键时长，防过冲

这就是 PD 控制的精髓：P 负责"现在偏差多大"，D 负责"偏差变化多快"。

最终脉冲时长：

duration = p_ms × d_factor ± 10% 随机抖动
duration = clamp(duration, 12ms, 120~180ms)  # 上限随力度增大

加了一点随机抖动（±10%），模拟人类操作的微小不一致，避免过于机械。

长按 vs 点按：

大多数时候用短脉冲（点按），但以下情况切换为长按：

  • 绿条移动速度 > 1.5 像素/帧（说明鱼在剧烈挣扎）
  • 黄点偏离绿条中心超过 25% 半宽（偏太多了，得猛拉）

3.5 信号平滑 — 指数移动平均（EMA）

smoothed = prev × (1 - alpha) + current × alpha    # alpha = smoothing (默认 0.35)

检测结果每帧都有微小抖动（几个像素的偏差），EMA 平滑消除了这种高频噪声， 让 A/D 控制基于稳定的信号做决策。alpha 越大跟随越快但越抖，越小越稳但响应慢。

3.6 性能参数

  • 主循环间隔：默认 20ms（50 FPS），用 mss 全屏截图 + OpenCV 处理
  • 结果推送：queue.Queue(maxsize=2)，满了就丢旧帧，永远展示最新画面
  • 预览刷新：30ms 定时器拉取结果，不阻塞工作线程

四、FAQ

Q: 为什么开了管理员还是没反应？
A: 确认游戏在前台运行，BetterNTE 的「显示器」选择正确。如果你有多个显示器， 选游戏所在的那个。另外检查一下是不是被杀毒软件拦截了输入模拟。

Q: 绿条检测不到怎么办？
A: 点「测试识别」看日志。如果「匹配像素 = 0」，说明 HSV 颜色范围没覆盖到游戏中的颜色。 可以重新框选区域，确保框选的区域干净（没有其他绿色元素干扰）。

Q: A/D 控制一直过冲怎么办？
A: 把力度调低。过冲 = P 增益太大，每次按得太猛。降低力度相当于减小增益。

Q: 能不能后台运行？
A: 不能。BetterNTE 用的是屏幕截图（mss）+ DirectInput，都需要游戏在前台。 你可以在副屏操作其他东西，但游戏窗口不能被遮挡。

Q: 支持其他分辨率吗？
A: 支持。BetterNTE 在启动时自动检测显示器分辨率，你只需要在对应分辨率下重新框选区域并保存配置即可。
